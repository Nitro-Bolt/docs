# Runtime API Reference

## Properties and Methods

### `pause()`

:::important
This will be added in a future update.
:::

Pauses script execution. Functionally equivalent to pressing the pause button. Script execution can be resumed with [`resume()`](#resume).
```js
vm.runtime.pause();
```

### `resume()`

:::important
This will be added in a future update.
:::

Resumes script execution after being paused with [`pause()`](#pause). Functionally equivalent to pressing the pause button.
```js
vm.runtime.pause();
```
