NitroBolt lets you import external addons that will load when the page is loaded. This section will include basic information on how to make one.

Before starting, it is highly recommended that you have a good understanding of [JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript).

If you've ever developed addons for [Scratch Addons](https://scratchaddons.com/), the development process is very similar except for a few notable differences.

:::warning
Addons have full access to your projects, extensions, and everything else in the editor. Only load addons from creators you trust!
:::
